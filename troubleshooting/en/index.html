When MCP tools don't appear in Claude Desktop

After installing the MCP in Claude Desktop, if you can't verify that it's working, type "Check the Mweft MCP tools" in the chat window.

Typing the sentence above in the chat asks MemoryWeft MCP to report whether it's connected, along with the list of available tools.

If the tools still don't show up, fully quit Claude Desktop, relaunch it, and try the same prompt once more.
