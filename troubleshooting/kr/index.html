macOS

[macOS] MWeft를 어디에 둘까 — 다운로드/데스크탑/문서 폴더는 피하세요

Mac에서는 MWeft 압축을 홈 폴더(예: "mweft" 폴더)에 푸세요. 다운로드·데스크탑·문서 폴더는 피합니다.

macOS 개인정보 보호 기능은 앱이 다운로드·데스크탑·문서·iCloud Drive 안의 파일을 쓰는 것을 막습니다. MWeft가 거기 있으면 AI 클라이언트(Claude 등)가 메모리 서버를 시작하지 못하고 "failed"로 표시됩니다.

해결: MWeft 폴더와 메모리가 저장되는 폴더를 홈 폴더로 옮기세요. 그런 다음 Manager를 열어 Install MCP를 다시 누르고, AI 클라이언트를 재시작합니다.

macOS

[macOS] start-mweft.command가 안 열릴 때

더블클릭해도 아무 반응이 없으면, 파일을 우클릭 후 열기를 누르세요 — 처음 한 번만 하면 됩니다.

macOS는 서명되지 않은 앱을 첫 실행 때 막습니다. 파일 우클릭 → 열기 → 열기로 한 번 승인하면, 이후에는 일반 더블클릭으로 실행됩니다.

MCP

[Windows · macOS] MCP 서버가 "failed"로 뜰 때 — 로그 확인 후 대응

먼저 이걸 해보세요(대부분 해결됨): Manager에서 Install MCP를 다시 누른 뒤, AI 클라이언트를 완전히 종료(Mac: ⌘+Q)했다가 다시 켜기. 그래도 안 되면 로그를 확인합니다.

AI 클라이언트에서 mweft 서버를 열고 View Logs(로그 보기)를 누릅니다. 마지막 줄을 보고 아래에서 메시지를 찾으세요:

  • "No module named 'encodings'" (Mac) — MWeft가 보호 폴더에 있습니다. 폴더(와 메모리 폴더)를 홈 폴더로 옮긴 뒤 다시 설치하세요 (위의 macOS 설치 위치 항목 참고).
  • "Failed to spawn process" / "No such file or directory" — Manager에서 MCP를 다시 설치(Install MCP)하세요.
  • ".mwf config file not found" / "startup aborted" — 최신 버전으로 업데이트한 뒤 Manager에서 MCP를 다시 설치하세요.
  • "DLL load failed" / "VC++ Redistributable" (Windows) — start-mweft.bat를 다시 실행하세요. 계속 안 되면 Microsoft Visual C++ 재배포 패키지(x64)를 aka.ms/vs/17/release/vc_redist.x64.exe 에서 설치하세요.

다시 시도해도 로그의 시간(타임스탬프)이 안 바뀌면, 클라이언트가 서버를 다시 띄우지 않은 것입니다 — AI 클라이언트를 완전히 종료했다가 다시 켜세요.

MCP

Claude Desktop에서 MCP 기능이 확인되지 않을 때

클로드 데스크탑에 MCP 설치 시, 기능 확인이 어렵다면 채팅 창에 'Mweft MCP 도구 확인해줘' 라고 입력하세요.

채팅 창에 위 문장을 입력하면, MemoryWeft MCP가 현재 연결되어 있는지와 사용 가능한 도구 목록을 함께 알려줍니다.

그래도 도구가 확인되지 않는다면 Claude Desktop을 완전히 종료한 뒤 다시 실행하고, 동일한 문장으로 한 번 더 시도해 보세요.

Codex

[Codex] 프로젝트별 AI로 설치했는데 MCP가 안 보일 때 — 폴더 신뢰(trust)

Codex는 Desktop(데스크탑) 폴더에 대해 "이 폴더를 신뢰하겠습니까?" trust prompt가 자동으로 뜨지 않을 수 있습니다. 폴더를 신뢰해야만 설치된 MCP가 정상 동작합니다.

프로젝트별 AI로 설치하면, Codex가 해당 작업 폴더(예: Desktop)에 대한 trust prompt("이 폴더를 신뢰하겠습니까?")를 띄우고, 신뢰함을 선택해야 그 폴더에 설치된 MCP가 동작합니다. 그런데 이 prompt가 자동으로 나타나지 않는 경우가 확인되었습니다.

해결: 프로젝트 AI로 설치했는데 MCP가 안 뜬다면, 홈(사용자) 폴더 안의 .codex/config.toml 파일에 아래 2줄을 추가하고 Codex를 다시 시작하세요. 파일이 없으면 새로 만듭니다. 폴더 경로는 자신의 프로젝트 폴더 경로로 바꿉니다.

  • Windows: C:\Users\<사용자이름>\.codex\config.toml
  • macOS · Linux: ~/.codex/config.toml
[projects.'C:/Work/project']
trust_level = "trusted"

경로 구분자는 슬래시(/)를 사용하고, 작은따옴표(')로 감쌉니다. 저장 후 Codex를 완전히 종료했다가 다시 실행하면 설정이 적용됩니다.

ChatGPT

ChatGPT에서 MWeft MCP를 사용하고 싶을 때

ChatGPT 용 MCP 설치는 현재 정식으로 지원하지 않습니다. 다만 다음과 같은 방법으로 설치해 볼 수 있습니다.

이 문서는 Windows PC에서 실행되는 로컬 MemoryWeft(MWeft) MCP 서버를 ChatGPT의 사용자 지정 앱으로 연결하는 절차를 설명합니다.

1. 연결 구조

MemoryWeft Manager가 제공하는 MCP 서버는 기본적으로 로컬 stdio 방식입니다. ChatGPT는 이 프로세스에 직접 접속할 수 없으므로 다음과 같이 HTTPS MCP 주소로 변환해야 합니다.

MWeft stdio MCP
  -> Supergateway (Streamable HTTP)
  -> Cloudflare Tunnel (공개 HTTPS)
  -> ChatGPT 사용자 지정 MCP 앱

2. 준비물

  • Windows PowerShell
  • MemoryWeft Manager 및 생성된 프로젝트
  • Node.js
  • Cloudflared
  • 사용자 지정 MCP 앱을 만들 수 있는 ChatGPT 계정

설치 여부를 확인합니다.

node --version
npx.cmd --version
cloudflared --version

PowerShell 실행 정책 때문에 npx가 차단될 수 있습니다. 이 문서에서는 npx 대신 항상 npx.cmd를 사용합니다.

Cloudflared가 설치되지 않았다면 다음 명령으로 설치합니다.

winget install --id Cloudflare.cloudflared

설치가 끝나면 PowerShell을 닫았다가 다시 실행한 후 확인합니다.

cloudflared --version

3. MemoryWeft Manager에서 Show config 확인

MWeft 실행 경로와 도메인 설정은 임의로 작성하지 않고 MemoryWeft Manager에서 가져옵니다.

메뉴 위치:

MemoryWeft Manager
-> 설정
-> 도메인 설정
-> MCP 설치(AI 클라이언트)
-> ChatGPT Desktop
-> Show config

Show config에는 다음과 같은 JSON이 표시됩니다.

{
  "mcpServers": {
    "mweft": {
      "command": "D:\\...\\Mweft 설치 경로\\k2g-mcp.exe",
      "args": [],
      "env": {
        "K2G_USER_MEMORY_SAVE_GROUP": "default",
        "K2G_USER_MEMORY_SAVE_DOMAIN": "default_domain",
        "K2G_USER_SEARCH_TARGETS": "default_domain",
        "K2G_MCP_LAZY_INIT": "true",
        "EMBEDDING_PROVIDER": "onnx",
        "EMBEDDING_MODEL": "BAAI/bge-m3",
        "EMBEDDING_ONNX_PATH":"C:\\Mweft 설치 경로\\models\\bge-m3-onnx",
        "EMBEDDING_DIM": "1024",
        "DATA_DIR": "D:\\AI\\프로젝트 경로"
      }
    }
  }
}

이 JSON 전체를 ChatGPT에 붙여 넣는 것은 아닙니다. 다음 값만 이후 PowerShell 명령에 사용합니다.

  • command: k2g-mcp.exe 실행 경로
  • K2G_USER_MEMORY_SAVE_GROUP: 저장 그룹
  • K2G_USER_MEMORY_SAVE_DOMAIN: 저장 도메인
  • K2G_USER_SEARCH_TARGETS: 검색 대상 도메인
  • 임베딩 관련 설정
  • DATA_DIR: 프로젝트 데이터 폴더
JSON의 \\는 이스케이프 표현입니다. PowerShell 경로에는 일반 역슬래시 하나만 사용합니다.
JSON:       D:\\AI\\MemoryWeftTest
PowerShell: D:\AI\프로젝트 경로

저장 도메인과 검색 대상은 Manager에 표시된 값을 그대로 사용해야 합니다. 예를 들어 기존 기억이 Test 도메인에 있다면 이를 임의로 default로 변경하지 않습니다.

4. 환경변수 설정

새 PowerShell 창에서 Show config의 값을 적용합니다.

$env:K2G_DOTENV_FILE=""
$env:K2G_USER_MEMORY_SAVE_GROUP="default"
$env:K2G_USER_MEMORY_SAVE_DOMAIN="Test"
$env:K2G_USER_SEARCH_TARGETS="Test"
$env:K2G_MCP_LAZY_INIT="true"

$env:EMBEDDING_PROVIDER="onnx"
$env:EMBEDDING_MODEL="BAAI/bge-m3"
$env:EMBEDDING_ONNX_PATH="C:\Mweft 설치 경로\models\bge-m3-onnx"
$env:EMBEDDING_DIM="1024"
$env:DATA_DIR="D:\AI\프로젝트 경로"

위 값은 예시입니다. 특히 도메인과 경로는 자신의 Show config 값을 사용해야 합니다. K2G_DOTENV_FILE=""는 .mwf 파일을 사용하지 않겠다는 의미이며, EMBEDDING_PROVIDER와 EMBEDDING_ONNX_PATH는 Show config에 표시된 값(포터블 빌드는 onnx)을 그대로 사용합니다.

5. MWeft 실행 파일 확인

Show config의 command 경로가 실제로 존재하는지 확인합니다.

Test-Path "C:\...\Mweft 설치 경로\runtime\venv\Scripts\k2g-mcp.exe"

결과가 True여야 합니다.

6. Streamable HTTP 서버 실행

먼저 프로젝트 폴더로 이동합니다.

Set-Location "D:\AI\프로젝트 경로"

다음 명령을 한 줄로 실행합니다. --stdio 뒤의 경로는 자신의 Show config에 있는 command 값으로 바꿉니다.

npx.cmd -y supergateway --stdio '"C:\...\Mweft 설치 경로\runtime\venv\Scripts\k2g-mcp.exe"' --outputTransport streamableHttp --port 8000 --streamableHttpPath /mcp --healthEndpoint /healthz

정상적으로 실행되면 다음과 비슷한 로그가 표시됩니다.

[supergateway] Listening on port 8000
[supergateway] StreamableHttp endpoint: http://localhost:8000/mcp

이 PowerShell 창은 종료하지 않습니다.

7. 로컬 서버 상태 확인

새 PowerShell 창을 열고 실행합니다.

Invoke-WebRequest http://localhost:8000/healthz

다음과 같이 200과 ok가 나오면 정상입니다.

StatusCode : 200
Content    : ok

8. HTTPS 터널 생성

새 PowerShell 창에서 실행합니다.

cloudflared tunnel --url http://localhost:8000

잠시 후 다음과 같은 임시 HTTPS 주소가 표시됩니다.

https://random-name.trycloudflare.com

ChatGPT에 등록할 최종 MCP 주소는 끝에 /mcp를 붙인 주소입니다.

https://random-name.trycloudflare.com/mcp

Cloudflared가 실행 중인 PowerShell 창도 종료하지 않습니다. 임시 터널을 다시 실행하면 주소가 바뀔 수 있습니다.

ChatGPT에서 다음 메뉴로 이동합니다.

MWeft의 mweft_remember 도구로 이 내용을 저장해줘.

다음을 확인합니다.

  • Supergateway PowerShell 창이 실행 중인가?

  2. Supergateway 실행 창

두 프로세스를 종료하면 외부에서 MWeft에 접속할 수 없습니다.

13. 보안 주의

trycloudflare.com 임시 터널과 인증 없음의 조합은 짧은 연결 시험에 적합합니다. URL을 아는 외부 사용자가 MWeft의 기억을 조회하거나 쓰기 도구를 실행할 위험이 있으므로 주소를 공유해서는 안 됩니다.

지속적으로 운영하려면 다음 구성을 권장합니다.

  • 고정 Cloudflare Tunnel
  • Cloudflare Access 등의 접근 제어
  • OAuth 또는 별도의 인증 계층
  • 읽기 도구와 쓰기 도구의 권한 분리
  • 개인 기억이 아닌 별도 테스트 도메인에서 최초 검증
Supabase

Supabase에서 서비스하는 Postgres(무료)에 연결이 안 될 때

무료 플랜의 Direct connection은 IPv6 전용이라, IPv6를 사용할 수 없는 네트워크에서는 연결이 실패합니다(host 도달 불가 / timeout). Session pooler 연결 문자열(포트 5432)을 사용하세요.

원인

Supabase 무료 플랜의 Direct connection은 IPv6 전용 주소만 제공합니다. 가정·사내 네트워크나 일부 클라우드 환경처럼 IPv6를 지원하지 않으면 호스트에 도달하지 못해 연결이 timeout 됩니다.

해결

Session pooler 연결 문자열(포트 5432)을 사용하세요. Session pooler는 IPv4로 접속할 수 있어 IPv6 미지원 환경에서도 동작합니다.

  • ✅ Session pooler — 포트 5432
  • ❌ Transaction pooler — 포트 6543 (사용하지 마세요)

Transaction pooler(6543)는 트랜잭션 단위로 연결을 재사용·회수하기 때문에, 장수명(long-lived) 연결이나 prepared statement에 의존하는 클라이언트에서는 동작이 깨질 수 있습니다.

연결 문자열 위치: Supabase 대시보드 → Project Settings → Database → Connection string → Session pooler.

  3. 그래도 적용되지 않으면 PC를 재부팅하세요.
